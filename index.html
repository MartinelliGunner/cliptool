About ClipTool

ClipTool is a private desktop application that runs on its owner's own Windows computer. It is used by one person to manage one YouTube channel, @longlat11. It is not offered, sold or made available to anyone else, and it has no public website, login page or user accounts.

ClipTool uses the YouTube Data API to:

  • find recent and trending public videos on the channel's topics (cars and car deals, technology and AI);
  • upload short vertical clips (Shorts) to the owner's own channel, with captions, a title, a description and a credit line linking the original video;
  • set thumbnails and update titles on the owner's own uploads;
  • read the owner's channel and upload list, so the same video is not posted twice.

What data ClipTool uses

  • Google account authorisation. When the owner signs in, Google issues an access token that lets ClipTool act on the owner's YouTube channel. ClipTool requests only the YouTube permissions it needs for the actions above.
  • Channel and video information. The owner's channel ID, upload list, and the titles, IDs and statistics of the owner's uploads.
  • Public video information. Titles, view counts, durations and other public details of videos returned by YouTube search and trending charts.

ClipTool does not collect data from any other YouTube user, viewer or channel owner. It does not use cookies, analytics, advertising identifiers or tracking of any kind.

How data is stored

Everything stays on the owner's own computer. The access token is saved in a local file in the app's folder, and a local record of uploaded clips is kept so videos are not posted twice. Nothing is sent to any server operated by ClipTool, because there is none. Local files are deleted when the owner deletes them or removes the app.

Sharing

ClipTool does not sell, rent or share any data with third parties. Data is only exchanged with Google and YouTube, through the YouTube API, to carry out the actions listed above.

YouTube API Services

ClipTool uses YouTube API Services. By using ClipTool, the user agrees to be bound by the YouTube Terms of Service, and the Google Privacy Policy applies to data handled through the YouTube API.

The YouTube data ClipTool accesses is listed under "What data ClipTool uses" above. It is used only to find videos and to upload and manage Shorts on the owner's own channel.

Deleting data

  • ClipTool keeps no data on any server. Everything it stores is in files on the owner's own computer: the sign-in token, the IDs of videos it has already checked, the record of the owner's own uploads, and working copies of clips.
  • Downloaded source videos are deleted after the clips are made.
  • The owner can delete all stored data at any time by deleting the ClipTool folder, or only the token file youtube_token.json, the run history autopilot_state.json and the uploaded.json records.
  • Revoking access as described below stops ClipTool from using the stored token.
  • Questions about data can be sent through the contact below.

Revoking access

Access can be withdrawn at any time from the Google account's security settings at myaccount.google.com/permissions. Deleting the local token file also stops the app from acting on the channel.

Terms of use

  • Who may use it. ClipTool is a private tool used only by its owner on their own computer for their own YouTube channel. It is not offered to the public and has no other users.
  • YouTube terms. Use of ClipTool requires agreeing to the YouTube Terms of Service and is subject to the Google Privacy Policy. ClipTool's use of the YouTube API follows the YouTube API Services Terms of Service and Developer Policies.
  • Content. Clips posted with ClipTool credit and link the original video. Content is removed promptly if a rights holder objects.
